Lists help block known advertising, tracking, scam and malware domains. They cannot inspect encrypted page content or replace safe browsing habits.

Country ranges come from IPdeny and may block shared CDNs. They describe address allocation, not a guaranteed physical server location. IPv6 forwarding is disabled. Apps using their own encrypted DNS may bypass domain filtering; IP blocks still apply.

PRIVACY CONTROLS

Your route to the Internet

Checking privacy settings.

Both modes validate DNSSEC and cache responses locally. DNS follows the active protected tunnel.

Only a single full IPv4 tunnel is accepted. Imported scripts, hooks and custom routes are rejected. IPv6 routing is disabled.

Protected modes block direct client access if the tunnel fails. To sign into a hotel network, explicitly select Direct, complete its sign-in, then re-enable your protected mode. HTTPS CONNECT supports TCP; unsupported UDP traffic is blocked.
